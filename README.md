## 🌍 Sobre o Projeto

O **Partiu Destino** foi desenvolvido para facilitar a divulgação e venda de pacotes turísticos através de uma plataforma moderna e intuitiva.

O sistema permite que usuários explorem destinos, visualizem pacotes disponíveis, realizem solicitações de viagens personalizadas e gerenciem seu carrinho de compras.

Além disso, conta com uma área administrativa para gerenciamento completo do conteúdo da plataforma.

## 🚀 Como Executar

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/partiu-destino.git
```

### 2. Acesse a pasta

```bash
cd partiu-destino
```

### 3. Configure o banco de dados

Edite o arquivo:

```json
appsettings.json
```

Inserindo sua conexão MySQL.

### 4. Execute o projeto

```bash
dotnet restore
dotnet run
```

### 5. Acesse

```text
https://localhost:xxxx
```
